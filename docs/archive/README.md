# Archive

This directory keeps completed or superseded planning material out of the active documentation path.

Rules:

- Keep one canonical copy of each completed plan.
- Do not add new implementation work here.
- If archived material is still used by an audit or runbook, link to its archived path explicitly.
- Prefer deleting exact duplicates over preserving multiple stale copies.

Current archived plan sets:

- `plans/feature-plans/emet-superrouter/` — completed Superrouter phase plan, including generated `plan.html`.
- `plans/FUTURE_ROADMAP.md` — superseded future roadmap notes.
- `plans/general/` — older project and router plans.
- `plans/superpowers/plans/` — completed agent workflow plans.
