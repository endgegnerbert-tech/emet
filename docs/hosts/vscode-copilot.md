# VS Code / Copilot

## Install

```bash
npm install -g @black-knight.dev/emet
emet init vscode-copilot --write
```

## Config file

Repo example: [`configs/vscode-copilot/mcp.json`](../../configs/vscode-copilot/mcp.json)

## Verify

Restart VS Code and confirm Copilot Chat sees the `emet` MCP server.
