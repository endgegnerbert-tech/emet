# Pi Coding Agent

## Install

```bash
pi install npm:@black-knight.dev/emet
```

## Verify

Use a prompt like:

```text
Use emet to verify the current Node.js test runner docs.
```

The Pi extension keeps the public `emet` tool contract and also ships `web_fetch`.

If `web_fetch` does not appear right after install, run `/reload` or restart pi. The tool name is exactly `web_fetch` (with underscore), not `webfetch`.
