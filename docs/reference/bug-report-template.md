# Grounding bug report template

Use this when `emet` looks wrong and you want a report maintainers can act on.

## Include

- emet version
- host/runtime (`Pi`, `Claude Code`, `Codex`, `Cursor`, `Gemini`, `VS Code/Copilot`, CLI)
- query
- mode
- relevant options
- expected result
- actual result
- cited source URLs
- `runtimeTrace` if available

## Redact before sharing

Remove:

- tokens
- cookies
- secrets
- private local file paths unless necessary
- proprietary source text unless necessary
